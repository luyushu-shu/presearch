# presearch

> 自研全屋空间智能底座预研：摄像头（主模态）+ 移动设备人物房间定位 × 无唤醒词全时语音助理与家庭纪要

脱离 Home Assistant 框架、从零重构一套全屋系统之前的预研究（pre-search）仓库。核心设想是把两个方向合流成一个底座：

1. **人物定位**：基于固定摄像头与移动设备（手机等），判断每位家庭成员当前在哪个房间；
2. **全时语音**：以摄像头为主要感知模态，声音作为辅助通道——无唤醒词、实时录音转写，在合适的时候主动介入对话，其余时间静默沉淀为会议纪要 / 家庭备忘与情景记忆。

本仓库目前是**论文预研与架构对齐**阶段的成果，不是可运行的系统代码。

## 背景与动机

原先系统构建在 Home Assistant 之上，现已全部自研重做。本仓库沉淀重做前针对以下问题查阅的里程碑与近期（2025–2026）预印本论文，来源以 [alphaXiv](https://www.alphaxiv.org/) 为主：

- 摄像头与移动设备怎样融合，才能可靠地回答「哪个家庭成员在哪个房间」？
- 无唤醒词、常开的语音助理怎样判断「这句话是不是对它说的」「现在该不该插话」？
- 不插话的时候，持续转写能沉淀成什么（会议纪要、家庭备忘、长期记忆）？

## 为什么脱离 Home Assistant

HA 的核心抽象是离散的「实体状态 + 自动化触发器」，而新系统需要的是连续的时空流：

| 维度 | Home Assistant 的基因 | 本系统需要的形态 |
| --- | --- | --- |
| 人物在场 | `binary_sensor` 开/关、区域触发 | 跨房间连续概率分布与轨迹（人在移动、手机可能没带） |
| 语音 | 回合制语音管道（唤醒 → 一问一答） | 毫秒级多麦仲裁、全双工流、何时说话的时机门控 |
| 多模块关系 | 各集成各自维护状态 | 定位、语音、记忆共享同一张「全屋世界状态图」 |

底层 Zigbee / Matter 等设备协议仍可借力现成桥接（如 Zigbee2MQTT、Matter Server），自研精力应集中在**全屋世界状态图（World State Graph）+ 多模态流式感知与主动决策层**。

## 系统设想：一个底座、两个出口

```text
                ┌─────────────────────────────────────────────┐
摄像头帧 ──────►│  常驻感知层                                  │
麦克风流 ──────►│  · 多相机人物检测/轨迹 · 手机无线/IMU 关联   │
手机信号 ──────►│  · 流式带说话人转写 · 声纹/人脸识别          │
                └──────────────────┬──────────────────────────┘
                                   ▼
                ┌─────────────────────────────────────────────┐
                │  全屋世界状态图（World State Graph）         │
                │  谁在哪间房 · 手机是否随身 · 房间活动/设备态  │
                └──────────────────┬──────────────────────────┘
                                   ▼
                ┌─────────────────────────────────────────────┐
                │  轻量门控分流器（何时开口 / 对谁说 / 多大声）  │
                └─────────┬───────────────────────┬───────────┘
                          ▼                       ▼
                主动对话出口                静默纪要与记忆出口
                高价值、低打断代价时        家庭备忘 · 待办 ·
                才开口介入                  情景记忆库（反哺下次介入）
```

关键原则（来自预研结论）：

- **快慢解耦**：不用大模型高频轮询决定「要不要说话」；由毫秒级轻量门控（如时序图/小型分类头）常驻过滤，大模型只在门控通过后被唤醒生成内容。
- **代价敏感**：介入决策显式权衡「误打断代价」与「漏帮代价」，并随房间与人物状态变化（卧室夜间、书房专注时自动更克制）。
- **双向闭环**：定位缩小语音的声纹候选池与拾音范围；语音声纹又能反向刷新「某成员进了无摄像头房间」的位置锚点。

## 两大方向的设计要点

### 1. 摄像头 + 移动设备的人物房间定位

- **人机分离陷阱**：手机忘在书房充电、人去了厨房时，BLE/Wi-Fi 会误判。需引入「人机绑定置信度」：手机 IMU 长期静止且摄像头看到该成员移动时，自动降权手机信号。
- **隐私房盲区**：卧室/卫生间通常无摄像头。靠房间拓扑连通图 + 当日衣着短期 Re-ID + 门廊进出事件做状态传递（人不能瞬移）。
- **自动校准**：用摄像头视觉真值在日常走动中自动标注手机无线指纹，避免人工逐房间采指纹；相机几何可用视觉基础模型免标定恢复。

代表性工作：RADAR (2000)、ViFiCon / ViFiT (2022–2023)、CorVS+ (2025)、视觉辅助无线自标定 (2025)、免标定多相机 3D 追踪 (2026)。

### 2. 全时实时语音：无唤醒词主动助理 + 家庭纪要

- **指向检测**：融合声学特征、ASR 不确定性与视觉线索（人脸朝向、注视、唇动）与短期交互历史，判断话是对设备说的还是家人闲聊。有摄像头房间走音视频融合，无摄像头房间退化为纯音频 + 历史。
- **介入时机**：「内心想法」先在后台生成并评分；高价值才开口，中等置信走轻量提示，低价值直接写入家庭纪要。
- **多房间音频**：先做房间声场仲裁选主拾音节点，人移动时回复跟随切换（Follow-Me Audio）；卧室有人休息时禁止外放、访客在场时私密内容改走静默通知。
- **纪要即记忆**：餐桌/客厅闲聊不插嘴，后台按说话人沉淀待办、承诺、物品消耗，形成家庭情景记忆，供日后主动提醒调用。

代表性工作：Horvitz et al. (1999)、Alexa Follow-Up DDSD (2018)、VAP (2022)、Moshi (2024)、SAS (2026)、LlamaPIE (2025)、Inner Thoughts (2025)、PRISM (2026)、ROMA (2026)、JEDIS-LLM (2025)、EgoMem (2025)。

### 智能家居 Agent 底座参考

- Sasha (2024)：LLM 把「让屋里舒服点」类模糊目标拆成澄清→过滤→规划→执行→反馈。
- HearthNet (2026)：本地边缘编排，规划/校验/鉴权分层与设备执行租约，避免自动化互相打架。
- OmniSmartHome / PROME (2026)：「把这儿关了」「去我房间拿」等空间省略指代必须靠人物定位与视觉线索消歧。
- PersonalHomeBench (2026)：部分可观测家庭里，常驻状态维护器 + 记忆检索器比单纯增强模型推理更关键。

## 预研论文全景

共 33 组核心工作，按六个子模块组织（完整表格、关键指标与逐篇「落地启示」见交互看板）：

| 子模块 | 里程碑 | 2025–2026 前沿 |
| --- | --- | --- |
| 全屋人物房间定位 | RADAR、ViFiCon/ViFiT、多住户追踪综述与 UMTF | CorVS+、免标定 3D MCPT/SCOUT、视觉辅助无线自标定、DASEL |
| 全屋空间 Agent 底座 | Sasha、LAHAR | OmniSmartHome/PROME、HearthNet、PersonalHomeBench/SMH-Bench |
| 无唤醒词与全双工 | Bohus & Horvitz (2009)、Alexa DDSD (2018)、VAP、Moshi | SAS、AV-Dialog、Endpoint Anticipation、Duplex-MPE |
| 介入时机门控 | Horvitz (1999)、Proactive Agent (ICLR 2025) | LlamaPIE、Inner Thoughts、PRISM、TGL Trigger Gate |
| 音视频流式交互 | VideoLLM-online (2024) | ROMA、EgoSocial/DIVE |
| 实时转写与家庭纪要 | Whisper-Streaming、EEND/QMSum | JEDIS-LLM/Dixtral、在线会议摘要/EgoMem |

部分关键量化结论：

- 摄像头辅助可把端侧无唤醒词指向检测 F1 从纯音频 0.86 提升到音视频 0.95（SAS, 2026，60 小时多人测试，<150 ms / <20 MB）。
- 视觉-手机轨迹关联结合可靠度加权，可把多人身份定位 F1 从传统步态匹配 0.131 提升到 0.761（CorVS+, 2025）。
- 风险敏感代价门控可把主动介入误打断率从 50.2% 压到 22.9%、F1 升到 86.6（PRISM, 2026，ProactiveBench）。
